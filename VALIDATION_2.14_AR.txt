AL-thmany Extractor 2.14.0 — Unified Group Memory
==================================================

نطاق التعديل
------------
- تطبيق Android Native يعمل مع تطبيق WhatsApp الحقيقي عبر Accessibility/Android UI.
- قاعدة قروبات موحدة مشتركة بين الاستخراج والنشر.
- لا يتم حفظ AccessibilityNodeInfo؛ كل تفاعل يطلب Root حديثًا.
- GroupRecord يحفظ package وID/JID إن توفر وطرق الوصول وآخر نجاح/فشل وحالة النشر الأخيرة.
- فتح القروب: Cached non-search → Visible List → Scroll + Match → Search fallback أخير.
- الاستخراج Event-first مع Link classification + dedupe + source group/package metadata.
- الفحص يدعم: فحص فقط / انضمام فقط / فحص + انضمام.
- طلب الانضمام للمجموعات التي تحتاج موافقة خيار مستقل وغير مفعل افتراضيًا.
- بعد إجراء Join/Request، النتيجة غير المحسومة تصبح ACTION_UNCERTAIN ولا يعاد الضغط أعمى.
- النشر يعيد استخدام نفس GroupRecord/GroupAccessRouter ويسجل آخر حالة نشر في ذاكرة القروب.
- اختيار/استخراج القروبات مقيد بنسخة WhatsApp المحددة لتجنب خلط WhatsApp وBusiness.

قيود تقنية مقصودة
------------------
- لا يوجد مسار رسمي ثابت في WhatsApp Android لفتح قروب بواسطة JID مباشرة؛ يتم حفظ JID إذا ظهر من مصدر موثوق ولا يتم ادعاء Direct JID غير مدعوم.
- Shizuku backend الحقيقي غير مضاف في 2.14.0؛ المحرك الحالي Accessibility + Android native intents/actions.
- لم يتم تنفيذ Full Android Gradle compile محليًا لأن بيئة التسليم لا تحتوي Android SDK/Gradle كاملين. GitHub Actions المرفق هو اختبار build النهائي للـAPK.
